「NTT株って、本当に配当金が増え続けるの？」

高配当株として人気のNTTですが、

- 株価が安くて買いやすい
- 配当利回りも高め
- NISAとの相性も良い

と言われる一方で、

「通信株って今後も成長できるの？」

「増配はいつまで続くの？」

「100株だけでも意味ある？」

と不安を感じる人も多いと思います。

特に最近は、株価が150円前後まで下落しており、

「今が買い時なのか」

「もっと下がるのか」

迷っている人も増えているはずです。

この記事では、

- NTTの配当金推移
- 100株・1000株でいくらもらえるのか
- 今後の増配予想
- NISAで持つメリット
- 高配当株としての評価

を初心者向けにわかりやすく整理していきます。

## NTT株の現在の株価・配当利回り

2026年5月17日時点のNTT株の情報はこちらです。

| 項目 | 数値 |
|------|------|
| 株価 | 151.8円 |
| 配当金（予想） | 5.4円 |
| 配当利回り | 3.56％ |
| PER | 12.61倍 |
| PBR | 1.27倍 |
| 最低購入金額 | 約15,000円 |

NTTの魅力は、なんといっても

👉 **「少額で始めやすい高配当株」**

という点です。

100株でも約15,000円。

高配当株の中ではかなり買いやすい価格帯です。

## NTTの配当金推移｜実はかなり優秀な増配株

NTTは長年にわたって増配を続けています。

| 年度 | 1株配当 |
|------|---------|
| 2018 | 3.0円 |
| 2019 | 3.6円 |
| 2020 | 3.8円 |
| 2021 | 4.2円 |
| 2022 | 4.6円 |
| 2023 | 4.8円 |
| 2024 | 5.1円 |
| 2025 | 5.2円 |
| 2026 | 5.3円 |
| 2027予想 | 5.4円 |

ここで大事なのは、

👉 **「派手ではないけど、安定して増配している」**

という点です。

高配当株投資では、

- 一時的に利回りが高い銘柄
- 無理に配当を出している銘柄

よりも、

"長く増配できる企業"

の方が重要です。

NTTはまさにそのタイプだと思います。

## NTT株を100株・1000株持つと配当金はいくら？

2027年予想配当（5.4円）で計算すると、年間配当金は以下のようになります。

| 保有株数 | 年間配当金 |
|---------|-----------|
| 100株 | 540円 |
| 500株 | 2,700円 |
| 1000株 | 5,400円 |
| 5000株 | 27,000円 |

「思ったより少ない」

そう感じる人もいるかもしれません。

でも、高配当株投資は、

👉 **"最初の配当金"より"将来の積み上がり"**

が重要です。

NTTは、

- 株価が安い
- 毎月買い増ししやすい
- 増配期待がある

ので、コツコツ積立との相性がかなり良い銘柄です。

## NTTは今後も増配できる？将来予想を考察

ここが一番気になるポイントですよね。

結論から言うと、

👉 **「急成長は難しくても、緩やかな増配は期待できる」**

と考えています。

理由は大きく3つあります。

### ① 通信事業が超安定

NTTは通信インフラ企業です。

景気が悪くなっても、

- スマホ
- インターネット
- 法人通信

は簡単には止まりません。

つまり、業績が急激に崩れにくい。

これは高配当株にとってかなり重要です。

### ② キャッシュフローが強い

NTTは毎年かなり大きな営業キャッシュフローを生み出しています。

2025年でも営業CFは約2.36兆円。

これは、

👉 **「本業でしっかり現金を稼げている」**

という意味です。

配当金は"利益"だけではなく、"現金"が重要。

その意味で、NTTはかなり強い企業です。

### ③ 配当性向がまだ極端ではない

2026年の配当性向は約42％。

高配当株としては、まだ無理のない水準です。

つまり、

- 今後も少しずつ増配余地がある
- 利益が多少落ちても維持しやすい

と考えられます。

## ただしNTT株にも注意点はある

もちろん、良いことばかりではありません。

### 利益成長はそこまで強くない

NTTは成熟企業です。

そのため、

- 株価2倍3倍
- 爆発的成長

を期待する銘柄ではありません。

どちらかというと、

👉 **「安定配当を積み上げる銘柄」**

として見る方が自然です。

### 有利子負債が増えている

2026年は有利子負債がかなり増加しました。

自己資本比率も20.8％まで低下しています。

大型投資の影響もありますが、

- 金利上昇
- 財務負担

には今後注意が必要です。

## NISAでNTTを持つメリット

NTTはNISAとの相性がかなり良いです。

理由はシンプルで、配当金が非課税になるから。

通常、配当金には約20％の税金がかかります。

例えば年間1万円の配当でも、実際に受け取れるのは約8,000円程度。

でもNISAなら税金がかかりません。

特にNTTは、

- 長期保有向き
- 増配期待
- 少額投資しやすい

ので、

👉 **「NISAで高配当株を始めたい」**

という人とかなり相性が良いと思います。

## NTT株は今買い時？PERから考える

現在のNTTのPERは約12.6倍。

過去のPER推移を見ると、10〜15倍程度で推移することが多い銘柄です。

つまり今は、"極端な割高ではない"水準と考えられます。

急騰を期待する銘柄ではありませんが、

- 安定
- 配当
- 増配

を重視するなら、比較的検討しやすい価格帯だと思います。

## NTT株はこんな人に向いている

NTTは、

- 高配当株初心者
- NISAで配当を積み上げたい人
- 安定企業を長期保有したい人

にはかなり相性が良い銘柄です。

逆に、

- 短期で大きく儲けたい
- 成長株を狙いたい

という人には少し物足りないかもしれません。

## 投資判断に迷うなら、相談するのも選択肢

高配当株投資って、

- 利回り
- 増配率
- PER
- 財務
- NISA

など、考えることがかなり多いです。

特に最近は、

「自己流でやっているけど、本当にこれでいいのかな…」

と不安になる人も増えています。

実際、

- NTTをどのくらい持つべきか
- NISAをどう使うか
- 高配当株と投資信託をどう組み合わせるか

は、人によって正解が変わります。

だからこそ、一度プロに相談して整理してみるのはかなりアリだと思っています。
